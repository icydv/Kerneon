# Changelog

All notable user-facing changes will be recorded here. Kerneon uses semantic versioning where practical; preview suffixes identify builds that have not reached a stable compatibility promise.

## 0.1.0-preview.1 — 2026-08-30

Initial open-source technical preview.

- Native Windows system, process, event, hardware and frame-delivery monitoring.
- Evidence-gated Surge session controls with journalling and exact rollback paths.
- Optional capability-gated NVIDIA NVML and AMD ADLX GPU/VRAM tuning laboratory.
- Responsive Remote Link dashboard, branded QR pairing and revocable local control leases.
- Native non-injected Frame HUD and local WebRTC screen/input preview.
- Easy and technical language modes, Hardware Passport, Event Lens and opt-in AI insights.
- GPL-3.0-only source release with no hidden usage reporting.

See [`docs/KNOWN_LIMITATIONS.md`](docs/KNOWN_LIMITATIONS.md) before enabling experimental features.
