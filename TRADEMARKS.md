# Kerneon name and branding

The source code is GPL-3.0-only. The **Kerneon** name and the Kerneon logo identify the official project created by Ryan Horth; the software licence does not grant permission to imply that an unofficial fork, binary or service is endorsed by the project.

Community forks may accurately say that they are based on or compatible with Kerneon. If a fork makes material changes or distributes its own binaries, use a distinct product name and make the lack of official endorsement clear. Unmodified redistribution should preserve the copyright, licence and third-party notices.

This guidance exists to help users distinguish official downloads from modified builds, not to prevent good-faith discussion, reviews, screenshots or contributions.
